# gh-orbit docs

Feature-level reference for contributors. Top-level `CLAUDE.md` keeps only stack / layout / commands / hard rules; everything else lives here.

Reading order for a new contributor:

1. [architecture.md](architecture.md) — what the screen looks like and how panes compose.
2. [git-wrappers.md](git-wrappers.md) — how the TUI talks to git.
3. [config.md](config.md) — where logs and prefs go.
4. [checkout.md](checkout.md) — the largest behavioral surface (refs/graph `enter`, `p`, dirty-tree, fast-forward).
5. [stash.md](stash.md) — Stashes section and its write actions.
6. [branches.md](branches.md) — `n` / `d` / `m` branch lifecycle modals.

[index.md](index.md) is the same map in one-line form, optimized for Claude reading the repo.
